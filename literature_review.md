# Literature Review

## 1. UCI Machine Learning Repository — Iris Dataset

The UCI Machine Learning Repository describes the Iris dataset as a classic dataset for classification research. It contains 150 flower samples, four numerical features (sepal length, sepal width, petal length, and petal width), and three Iris species classes. The dataset is widely used for testing and demonstrating machine learning classification methods.

Source: UCI Machine Learning Repository — Iris Dataset  
https://archive.ics.uci.edu/dataset/53/iris

## 2. Fisher (1936) — The Use of Multiple Measurements in Taxonomic Problems

Fisher's original research used multiple measurements of Iris flowers to study differences between species. The study showed that measurements such as sepal and petal dimensions can help distinguish different groups of Iris flowers and became an important foundation for classification research.

Source: Fisher, R. A. (1936), The Use of Multiple Measurements in Taxonomic Problems.

## 3. Aziz & Awrahman — Prediction Model Based on Iris Dataset

This study investigated the use of several supervised machine learning algorithms for predicting Iris flower species. The research considered algorithms such as Logistic Regression, K-Nearest Neighbors, Decision Tree, and Random Forest using flower measurements as input features.

Source: Aziz, C. F., & Awrahman, B. J., Prediction Model Based on Iris Dataset Via Some Machine Learning Algorithms.

## 4. Mithy et al. — Classification of Iris Flower Dataset Using Different Algorithms

This research compared different machine learning approaches for classifying Iris flowers. The study used the four physical measurements of Iris flowers as input features and examined different algorithms to determine their classification performance.

Source: Mithy, S. A., Hossain, S., Akter, S., Honey, U., & Sogir, S. B. (2022), Classification of Iris Flower Dataset using Different Algorithms.
