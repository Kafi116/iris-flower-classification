\# Iris Flower Classification



\## Project Overview

This project focuses on classifying iris flowers into three different species using machine learning classification techniques.



\## Research Question

Can the species of an iris flower be predicted using its sepal length, sepal width, petal length, and petal width?



\## Dataset

The project uses the Iris Dataset, a well-known public dataset for machine learning classification.



Dataset Source: UCI Machine Learning Repository



\## Machine Learning Technique

Classification



\## Planned Model

K-Nearest Neighbors (KNN)
